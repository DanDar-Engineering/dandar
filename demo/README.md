# Демо (showcase)

## Бэлтгэл

1. Бүгдийг асаах (Ubuntu дотор): `bash scripts/start-all.sh` — утсаар үзүүлэх бол `--host`.
2. Демо өгөгдөл: `pnpm run seed:demo` — **демо эхлэхийн өмнөхөн** ажиллуулна. Өнөөдрийн
   давтлага, 10 минутын дараа эхлэх сесс, маргаашийн эссэ зэрэг нь одоогийн цагаас тооцогдоно.
3. Шалгах (заавал биш, 3–5 мин): `pnpm run smoke` — бүх функцийг Gemma 4-тэй нь шалгана.
4. erxes-д нэвтрээд **Тохиргоо → Холболтууд** дээр Gemma 4, дуу унших ногоон байгааг харна.
5. Демо өгөгдлийг устгах: `pnpm run seed:demo -- --reset` (өөрийн өгөгдөлд хүрэхгүй).

## Юу нэмэгдэх вэ

| Хэсэг          | Өгөгдөл                                                                       |
| -------------- | ----------------------------------------------------------------------------- |
| Зураг уншуулах | 3 тэмдэглэл (Математик, Биологи, Физик), 3 шалгалтын материал                 |
| Багш           | Математикийн сорил ирсэн, Физикийн шалгалтад хариу өгсөн                      |
| Давтлага       | 4 багц, 38 карт; өнөөдөр ~19 карт; Физик ба Англи хэл «сул сэдэв»             |
| Шалгалт        | Физик 3 хоногийн дараа, Математик 11.06, Англи хэл 11.14                      |
| Ахиц           | Сүүлийн 7 хоногийн 6 өдөр давтсан, ~140 үнэлгээ                               |
| Төлөвлөгөө     | 5 даалгавар, 18 сесс, 2 сануулга хүлээж байна                                 |

Нэг erxes хэрэглэгч сурагч, багш хоёулаа болно. Тусдаа багш үзүүлэх бол erxes-д багийн гишүүн
урьж, `pnpm run seed:demo -- --teacher <имэйл>` гэж ажиллуулна.

## Танилцуулгын дараалал (~7 минут)

1. **Төлөвлөгөө** (`/dandar`) — 7 хоногийн календарь, «Төвлөрөх цаг» карт, Сануулга (2).
   «Дуугаар төлөвлөх»: _«Маргааш оройн долоогоос есөн цаг хүртэл математикийн сорилд
   бэлдэнэ. Баасан гаригт физикийн шалгалттай.»_ → Gemma даалгавар, сесс гаргана.
2. **Зураг уншуулах** — утасны камераар жинхэнэ дэвтэр, эсвэл `demo/scans/` доторх зургийг
   оруулна → Gemma 4 уншиж ангилна → шалгаад хадгална. **Багш** табд ирсэн материалд хариу өгнө.
3. **Давтлага → Карт нэмэх → Уншуулсан материал** — «Ньютоны хуулиуд» (карт болоогүй) →
   Gemma карт гаргана → засаж хадгална. Шалгалтын материал дээр «Шалгалтад бэлдэх» → шинэ
   дасгал, огноо автоматаар бөглөгдөнө.
4. **Өнөөдөр** — Space хариу, 1–4 үнэлгээ, «Сэжүүр», «Тайлбарлуулах»; «Илүү ойр давтах сэдэв».
5. **Тест, Ахиц, Шалгалт, Багц** — бэлэн байдал %, 7 хоногийн график, таамаглал.
6. **Тохиргоо** — Pure AI туслах чат.

Gemma заримдаа 10–60 секунд бодно; хүлээх зуураа юу хийж байгааг тайлбарлана.
